# Project Instructions

- Before changing UI, styles, layout, landing pages, templates, game screens, email visuals, or print views, read `DESIGN.md`.
- Preserve the `DESIGN.md` tokens and rationale unless the task explicitly changes the visual identity.
- If the visual identity changes intentionally, update `DESIGN.md` in the same change and run `npx -y @google/design.md lint DESIGN.md`.
